# 学习指南

这个目录已经更新到官方仓库最新代码（2026-10-02）。Notebook 的中文说明按英文源逐单元迁移；官方新增或修改的 7 个说明单元已重新翻译，代码单元格保持官方原样。

## 从哪里开始

先完成第 2 章和第 3 章。第 2 章建立 tokenizer、Qwen3 前向计算、KV cache 和文本生成的基础；第 3 章加入 MATH-500 和确定性答案验证器。每读完一个小节就运行对应单元格，先确认输入、输出和张量形状，再修改一个参数观察变化。

然后依次学习：

- 第 4 章：思维链提示、自洽性采样等推理时扩展。
- 第 5 章：让模型批评并修订自己的回答。
- 第 6 章：把答案验证器变成可验证奖励，用 RLVR 和 GRPO 训练推理模型。
- 第 7 章：研究裁剪、KL 和格式奖励等 GRPO 改进。
- 第 8 章：把较大教师模型的推理数据蒸馏到较小模型。

你目前在学 RL，重点放在第 3、6、7 章。第 3 章的验证器定义了奖励来源；第 6 章把奖励接入策略梯度；第 7 章解释如何让 GRPO 更新更稳定。阅读时始终追踪四个对象：模型生成的轨迹、验证器给出的奖励、同一问题多条回答之间的相对优势、用于更新策略的损失。

```powershell

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip

```

打开 `ch02/01_main-chapter-code/ch02_main.ipynb` 后，不要直接运行全部单元格。先运行环境检查和导入，再下载模型，确认最小生成流程正常后继续。第 5–7 章的完整实验会消耗较多显存和时间，先把数据量、生成长度和训练步数降到 Notebook 中的调试规模。

如果 PowerShell 不允许激活环境，可以直接运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\jupyter.exe lab
```

## 每个 Notebook 的读法

1. 先读文字，写出本节要解决的问题。
2. 运行最小代码路径，记录输入、输出和张量形状。
3. 手算一个短序列的 log-probability、奖励或优势。
4. 只改一个变量，比较验证准确率、生成长度或损失。
5. 最后再看 `*_exercise-solutions.ipynb`。
6. 用三句话记录改变了什么、为什么有效、代价是什么。
